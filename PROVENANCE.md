# Provenance and data lineage

## Public source
PhysioNet/CinC Challenge 2019 v1.0.0 training sets A and B, PSV patient files.

## Deterministic lineage

`raw PSV`  
→ `01_build_core_arrays.py`  
→ `ALL_Xb.npy`, `ALL_Xs.npy`, `ALL_y.npy`, `ALL_pid.npy`, `split_seed42.npz`  
→ `02_build_trajectory_v2.py`  
→ `ALL_Xtraj_v2.npy`, `ALL_Xforward_v2.npy`  
→ `03_build_controls.py`  
→ `ALL_Xgeneric27.npy`, `ALL_Xnoise27.npy`  
→ `04_train_all_arms.py`  
→ per-seed validation/test predictions + multiseed table  
→ `05_calibration_utility.py` / `06_bootstrap_primary.py` / `07_crosssite.py` / `08_repeated_splits.py`  
→ manuscript statistical outputs.

No `ALL_*` file is required as an input to the end-to-end package. Every `ALL_*` array used downstream is generated by scripts in this archive from the public raw data.

## Canonical cohort ordering
Set A patient files are sorted lexicographically and assigned patient indices from 0. Set B is then sorted lexicographically and appended. For the official release, Set A contains 20,336 patients and Set B 20,000 patients. This ordering is part of the frozen provenance because cross-site scripts use the Set-A/Set-B patient-index boundary.

## Labels
`ALL_y.npy` is copied from the public hourly `SepsisLabel` column. Labels are never used to construct baseline temporal features, expert alerts/states, trajectory features, GenericTemporal27, or Noise27.

## Hash verification
`CANONICAL_ARRAY_SHA256.txt` contains hashes of the exact canonical generated arrays used for the reported study. `scripts/09_verify_reproduction.py` recomputes and checks these hashes after preprocessing.

## v1.1.1 integrity-gate revision

`run_all.py` now invokes `09_verify_reproduction.py --array-dir <work>` automatically after `03_build_controls.py` and before `04_train_all_arms.py`. Any mismatch in the canonical ALL_* or split hashes terminates execution before model fitting. A second verification is run after analysis to compare the reproduced multiseed table with archived reference results. No scientific feature definition, split, learner setting, or reported result changed from v1.1.0.
